# 输电检修窗口管控

本项目保存输电检修窗口管控所需的领域上下文、校验契约和作业管控服务，便于服务端功能围绕真实业务参与方展开。当前版本只提供资料读取、结构校验、命令行摘要和进程内管控服务，数据均为演示用虚构内容。

## 参与方

检修负责人、基建队伍、运维调度员、检测队伍（探伤/人工精检/无人机）、验收人员

## 事实资料

- 四川500千伏天林Ⅰ、Ⅱ线改造工程完成投运
- 工程包含新建铁塔、线路、避雷器、故障诊断装置和绝缘子更换
- 施工采用检修、X光探伤、即时消缺以及人工精检和无人机巡检

## 作业管控服务

`src/grid_maintenance/service.py` 的 `MaintenanceService` 在同一停电窗口内管控塔基施工、
绝缘子更换、X光探伤、故障诊断装置安装、人工精检与无人机复核：

- **隔离与窗口**：窗口按区段的安全隔离范围分配；同一隔离区不允许两个窗口并行停电；
  风险票必须经批准且覆盖窗口内全部工序，调度员才能批准停电。
- **现场锁定**：停电批准后由本窗口作业队伍现场确认隔离措施到位并锁定，锁定前禁止开工。
- **资质与授权**：开工同时校验人员资质和承包队归属，承包队只能更新本队作业；
  停送电只能由调度资质人员操作。
- **工序依赖**：前置工序未完成不得开工；新增缺陷（含中途故障）只暂停后续工序，
  已完成的探伤等结论及证据不可变、不可改写。
- **冲突升级**：同一设备人工检查与无人机结论冲突时，两份证据同时保留，
  自动生成升级复核单；复核关联缺陷未验收闭环则复核不能结案。
- **缺陷闭环与回避**：整改与验收分离，验收人不得验收自己整改的缺陷，
  验收退回的缺陷重新进入整改。
- **幂等与防重**：所有命令带命令编号，重复回执返回同一结果且不产生副作用；
  已恢复送电的窗口拒绝再次送电。
- **放行依据**：恢复送电时一次性校验全部工序闭环、缺陷验收、复核结案，
  并冻结放行依据快照（批准人、现场锁定人、闭环工序、验收缺陷、结案复核、送电调度员）。
- **逐级追溯**：`line_overview` 从线路总览下钻到区段、每基铁塔、每台设备、
  每项试验证据、缺陷整改/验收责任人与最终放行依据。
